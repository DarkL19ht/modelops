MODELOPS STAGE 10 — PERSISTENT LOCAL REGISTRY AND MODEL-SPECIFIC API

Prerequisite: You completed the Model Workspaces upload upgrade.

1. Unzip modelops_stage10_upgrade.zip into the root of ~/Documents/modelops.
   It only adds new files; no existing file is replaced.

2. Ensure .gitignore contains these two lines:
       var/
       demo_uploads/

3. Ensure your existing requirements.txt includes the Stage 9 skops dependency:
       skops>=0.11,<1
   Plus previous FastAPI/HTTPX and Streamlit/Requests dependencies.

4. From VS Code terminal:
       cd ~/Documents/modelops
       source .venv/bin/activate
       python -m pip install -r requirements.txt
       python scripts/create_loan_demo.py
       python -m pytest tests/test_workspace_registry.py -v
       python -m pytest -q

5. Local terminal 1 (read-only workspace API):
       python -m uvicorn src.modelops.workspace_api:app --host 127.0.0.1 --port 8001

6. Local terminal 2 (operator dashboard):
       MODELOPS_LOCAL_REGISTRY=1 python -m streamlit run dashboard/app.py --server.address 127.0.0.1 --server.port 8501

7. Open http://127.0.0.1:8501; select 'Persistent Registry' in sidebar.
   Upload loan-default model and CSVs from demo_uploads/loan_default/.
   Run monitoring, train candidate, and review checks. Promote only if eligible.
   Check inference and current model version at http://127.0.0.1:8001/docs.
   Restart Streamlit and the API and verify that workspace remains registered.

8. Git:
       git add src/modelops/workspace_registry.py src/modelops/workspace_api.py
       git add dashboard/pages/2_Persistent_Registry.py
       git add tests/test_workspace_registry.py docs/persistent_workspaces.md
       git add .gitignore
       git commit -m 'Add persistent local model registry and version-specific inference'
       git push origin main

DO NOT enable this registry operator page on the public Streamlit Cloud app or
start the workspace API on 0.0.0.0. It has NO authentication. DO NOT commit
var/ or demo_uploads/. Local model files persist, but Render Free storage does not.

See docs/persistent_workspaces.md for detailed guidance.
